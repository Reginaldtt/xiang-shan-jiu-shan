## 它能做什么

| 你的操作 | 实际发生的事 |
|---|---|
| 左滑，或点“保留” | 标记为已查看，原文件与目录不变 |
| 右滑，或点“加入待删” | 只加入待删清单，原文件仍在 |
| 点击相册 | 移动到手机中的真实媒体目录，成功后再看下一张 |
| 点击照片 | 全屏查看，支持缩放细节；视频可播放、暂停和拖动进度 |
| 点击“撤销” | 撤销最近的成功操作；撤销移动须实际恢复成功 |
| 点击“暂不决定” | 看下一项，这一项仍未处理 |
| 打开“重复检查” | 查找完整原文件相同的照片候选，由你逐份复核 |

相册来自系统允许访问的本地目录，可以搜索和新建。底部只显示相册名；在搜索列表中可查看完整路径，区分同名相册。新建的空相册在首次移入媒体后才可能出现在系统相册里，不会制造占位照片。

首页提供未整理/已整理、视频、截图和月份入口，也可以将已有相册配置为“已整理”。**“未整理”是应用的整理状态，并不是照片没有文件夹。** 整理状态、待删清单和当前进度保存在本机。

## 删除前，再确认一次

右滑不是删除。先进入“待删复核”，查看内容、取消不该删的项目，再主动选择交给系统回收站，并完成系统确认。

- 本版没有永久删除功能，不会按数量或时间自动清理。
- 系统确认取消或操作失败时，保留待删记录，不会改用永久删除。
- 回收站入口、保留期限和恢复能力由手机系统决定。请以手机实际显示为准，回收站不能代替备份。
- 分类不会压缩或重新编码原文件；同名文件不覆盖。权限取消或操作失败时不会显示分类成功。

## 离线使用

无广告、无订阅、无需登录；本版不申请联网权限，不上传照片，不需要 Google Play 服务。[隐私说明](PRIVACY.md)

重复检查只处理可访问的照片原文件，**不做相似图、连拍或视频去重，也不自动删除**。没有 AI 内容搜索、云端同步或 NAS 接入。

## 开始使用

1. 在 [最新版下载页面](https://github.com/vdisjok1-a11y/xiang-shan-jiu-shan/releases/latest) 找到 **Assets**，下载 `.apk` 文件。
2. 用手机打开 APK，按系统提示安装。打开后应用名称是“照片整理助手”。
3. 先用少量新拍照片或测试副本，按需授予媒体权限，再试保留、待删复核、移动和撤销。

**更新时直接覆盖安装，不要先卸载或清除应用数据。** 详细步骤与试用清单见 [安装与使用](INSTALL_AND_USE.md)。
